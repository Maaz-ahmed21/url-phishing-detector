Common Phishing Tactics

Phishers use cunning techniques to deceive victims into handing over credentials:

  • Typosquatting: Registering slight typos of popular brands (e.g. paypa1.com).
  • Subdomain Mimicry: Nesting legitimate names in subdomains (e.g. paypal.com.verify-login.net).
  • Raw IP Address: Using numeric hostnames to bypass domain lookup reputation.
  • Credential Obfuscation: Embedding the @ symbol to mask real targets.

How Machine Learning Detects Phishing

Our model evaluates structural parameters extracted directly from the URL string:

  • Entropy & Special Characters: High count of hyphens, dots, underscores, and equal signs.
  • Host Character Ratios: Numerical digit counts compared to alphabet letters.
  • Protocol Validation: Presence of standard HTTPS certificates vs raw HTTP.
  • Random Forest Classification: Decision tree ensembles trained on malicious dataset URL strings.
